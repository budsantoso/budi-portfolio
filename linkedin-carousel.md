## Design Specs (for Canva/Figma)

| Element | Spec |
|---------|------|
| Canvas | 1080 x 1080 px (square) or 1080 x 1920 px (story) |
| Background | `#0a0a0a` (dark) or `#ffffff` (light) |
| Primary text | `#ffffff` / `#0a0a0a` |
| Accent | `#3b82f6` (blue) or `#10b981` (green for success metrics) |
| Font | Inter or SF Pro Display |
| Font size | Headline 48-64px, Body 24-32px |

## Color Coding

| Type | Color | Usage |
|------|-------|-------|
| Success/Metrics | `#10b981` | Numbers, checkmarks |
| Error/Problem | `#ef4444` | X marks, warnings |
| Accent | `#3b82f6` | Links, highlights |
| Neutral | `#6b7280` | Secondary text |
