## 🚀 Getting Started

### Prerequisites
- Node.js 18.x or later
- npm, pnpm, or yarn

### Installation

```bash
# 1. Clone repository
git clone https://github.com/budsantoso/budi-portfolio.git
cd budi-portfolio

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

Visit `http://localhost:3000` in your browser.

### Build for Production

```bash
npm run build
npm run start
```
